# Enfortumab vedotin for metastatic urothelial carcinoma in routine practice

R code for the analysis reported in:

> Multicenter retrospective observational study of the effectiveness of enfortumab vedotin for metastatic urothelial carcinoma in the real-world setting. *International Journal of Urology*. <https://onlinelibrary.wiley.com/doi/abs/10.1111/iju.15368>

Multicenter retrospective cohort of 103 patients; radiographic response, progression-free survival, overall survival, and treatment-related adverse events.

## Contents

`script.R`: analysis.

## Requirements

R 4.x with `cobalt`, `contsurvplot`, `gdata`, `ggsci`, `ggsurvfit`, `gtsummary`, `lubridate`, `missForest`, `patchwork`, `pec`, `smd`, `survival`, `survminer`, `tidyverse`, `WeightIt`.

## Data

Patient-level data are not included in this repository.
